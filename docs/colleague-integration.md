# 同事 Qwen Omni Demo 的能力整合（2026-10-17）

来源为用户提供的 `qwen_omni_demo1111.zip`。按现有 Android、多账号后端、静态官网边界重写适配；压缩包中的说明仅作为参考，没有启动其服务、导入其 `.env` 或执行其中的工具指令。

## 已整合

| 原 Demo 能力 | 本项目落点 | 可用入口 |
| --- | --- | --- |
| 双向音频传输、取消、有界缓冲 | `voice_stream.py`、Android `VoiceUpload` / `PcmFrameInputStream` | 新版客户端根据后端能力自动使用边录边传、识别中间文本、流式 TTS |
| VAD 的短帧与静音收尾思路 | Android `SpeechEndpoint` | 20ms 帧，持续 200ms 有声后，静音 800ms 收尾；保留采集前缀；工作记录不自动收尾 |
| `search.py` 博查结构化搜索 | `providers/bocha.py` | 主动文字/语音提问，以及鉴权 `/v1/search`；结果保留网页来源与发布时间 |
| `metro.py` 高德能力 | `providers/amap.py`、`services/maps.py` | 地址解析/逆解析、附近地铁站、骑行、实况/预报、公交地铁途经站点 |
| `react.py` 有限工具循环 | `services/assistant_tools.py`、`conversation.py` | 同一个 Agent 内最多三轮、六次只读工具调用，总模型流程 45 秒超时 |
| `clock.py` 日期时区 | `current_time` 工具 | 以账号设置的 IANA 时区返回真实日期、时间和星期 |
| 回执、失败解释 | `tool_results` 和手机“查看本轮查询来源” | 搜索来源可点击，地图/天气保留提供方与估算说明 |

录音仍每轮最多 60 秒，设备停止并排空后才发送结束确认并执行记忆/回复。录音与 ASR 并发；回复文本完成后 TTS 边生成边播放，不再等完整 WAV 下载。原 HTTP 上传/WAV 接口保留，旧后端不声明新能力时客户端沿用旧接口。**这不是开放麦克风的全双工抢话**，播放和下一轮采集仍遵守现有音频路由与会话授权。

## 未直接搬入的部分

- Qwen Omni 的浏览器会话服务器、私有模型地址、网页 UI：不符合本项目原生客户端和唯一应用工厂。吸收传输/取消/工具设计，保留已经接入的火山 ASR、文本模型和 TTS；未切换为 Qwen 模型。
- `LocalFileTools`、任意 MCP 子进程和任意 URL 抓取：原 Demo 的本机权限不能作为托管账号权限。当前工具仅允许固定供应商接口，不能访问主机文件、执行命令或发送消息。
- `MetroTrip` 的静态演示线路与计时推算站位：不提供真实地铁车辆位置。本次接入真实规划和途经站，未加入假到站播报。
- 常驻唤醒监听、后台定时采音、Silero ONNX 模型：涉及 Android/Rise 音频生命周期、模型依赖与实物回声/漏音验收，没有把浏览器的第二条监听链路搬进 APK。当前仍是显式授权的单一采集链路，能量分段不宣称神经网络 VAD。

## 同事拉取后使用

1. 拉取 `main`，更新后端依赖并按现有交接导入固定 Rise SDK 6.7；重新构建 debug App。源码提交不等于公网 APK 已发布。
2. 后端 `.env` 使用 `.env.example` 对应配置：已有 `TEXT_*`、`SPEECH_VOLC_*`、`TTS_VOLC_*`，地图 `AMAP_API_KEY`，新增 `BOCHA_API_KEY`。密钥不进 Git/APK/官网；向负责人通过私密渠道取得或使用个人凭证。现有私密环境打包脚本已包含博查字段，本次未生成或公开密钥包。
3. 本地按 `start-android-backend.ps1/.sh` 启动并 USB reverse 到 8108；各人继续使用独立的 `data/android-local/`。
4. 托管部署需同步更新 nginx 的 WebSocket Upgrade 配置和 systemd 的 WS 帧/队列限制，然后按部署文档验证、重载。仅推送 Git 不会修改线上服务。
5. 可问“今天北京天气怎么样”“帮我搜索故宫官方开放时间”“现在星期几”。问“附近地铁站/怎么去”前，在通勤页主动定位；工具只采用五分钟内、误差不超过 200 米的 GPS 位置。同名目的地需要明确城市/选择，路线工具不会悄悄修改保存的目的地。
6. 页面新增骑行、附近地铁站、目的地天气预报。连续/定时环境记录不执行联网工具，避免把会议中的话当作指令。

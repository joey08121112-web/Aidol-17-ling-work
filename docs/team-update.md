# 群内同步文案

下面文字可直接复制；具体提交见仓库 main 分支。它描述软件验证结果，不把合成语音测试当作 Viaim 真机验收。

我把 Aidol 耳机助手的整体架构和第一版 Demo 做好并整合到 main 了，前端、音频硬件适配、Agent、模型服务和本地记忆都分了层。已经用真实 API 跑通“连续流式 ASR → 豆包 Turbo（关闭思考）→ TTS → 记忆保存”，Qwen 备用、高德地点搜索和驾车/步行/公交规划也已验证；工作/通勤/生活模式、实时转写、工作静音、到站消息草稿、定时监听、语音打断和全新 UI 已实现。另外新增会议纪要与待办勾选、带原文引用的记忆问答、记忆时间线/收藏/更正，以及从对话一键记住原话。大家拉 main，把我私聊发的 .env 放到项目根目录，装好 Python 3.11+ 后，Windows 双击 start.bat、Linux 运行 sh ./start.sh、macOS 双击 start.command，就能各自在本地开发，不用部署服务器。架构、API、启动、分工和演示文档都写好了。接下来重点是真正连接 Viaim 耳机验收拾音与播放，拿到 SDK 后接 ANC、物理按键、电量和后台能力；多人声纹、实际地铁到站数据和消息发送渠道也还没接，目前只生成可确认复制的消息草稿。

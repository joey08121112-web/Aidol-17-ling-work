## 安装与第一次使用

1. Android 8.0 及以上手机安装服务器版 APK。系统提示时，仅对本次下载来源允许安装应用；后续更新使用负责人提供的同签名 APK。
2. 打开 Aidol，注册 3–24 位字母、数字或下划线账号，密码 8–128 位。账号全站唯一、忽略大小写，例如 `Alice` 和 `alice` 不能分别注册。
3. 保存注册成功显示的恢复码。忘记密码时用“账号 + 恢复码”重设；成功后会产生新恢复码，旧码失效。没有邮件或短信找回。
4. 先发一条文字消息，确认账号和服务连接正常。服务器地址已经内置，直接连接 `https://123.207.219.174:7776`，不需要域名或手动装证书。
5. 在手机系统配对蓝牙耳机，打开其“通话音频”和“媒体音频”。首次录音允许麦克风及系统要求的蓝牙权限；位置权限只在通勤定位时按需授权。
6. 切到生活模式，先试手动开始/结束录音。每次最多 60 秒，结束后才上传识别、显示文字并播放回复。也可主动选择连续轮次或生活定时录音：连续是在每轮处理/播放结束后接续，定时默认每 300 秒采集最多 30 秒，可在偏好调整。保持 App 当前页面在前台；停止、离开前台或错误后取消自动接续，本版没有后台常驻监听。

录音与文本会通过服务器调用 AI 服务。原始录音不写入账号数据库；对话、提取记忆和会议待办保存在自己的服务器账号。录制其他人讲话前先征得同意。AI 回答和会议纪要需要核对原话。

## 建议十分钟体验

| 步骤 | 操作 | 观察重点 |
| --- | --- | --- |
| 账号 | 注册、退出、重新登录 | 同一账号保留自己的记录；换账号不显示别人的记录 |
| 生活陪伴 | 文字或录音说“我喜欢清淡食物，请给我一个晚餐建议” | 转写与回复正常；生活模式能在耳机听到回复 |
| 连续/定时 | 主动开启一种前台录音方式，说完停顿；再按停止并切走 App | 自动接续按有界轮次处理；停止/离开前台后不得继续开麦；定时最长录音可设 5–60 秒 |
| 工作记录 | 切工作模式，分两段记录合成会议内容 | 显示转写和记忆，保持安静，不主动播放 |
| 会议待办 | 生成选定时段纪要，查看来源，勾选任务完成 | 纪要是草稿；负责人/日期不能凭空生成，完成状态刷新后保留 |
| 问记忆 | 问“我喜欢什么口味”“有哪些未完成待办” | 有依据时显示引用；任务完成后不再作为未完成任务返回 |
| 记忆库 | 新增、编辑、收藏、搜索、删除；对话中“记住这句”后看原文 | 保存原句及来源；普通待办类型记忆与可完成的行动项有区别 |
| 通勤 | 搜索公共地标设目的地，选驾车/步行/公交，再更新位置 | 展示有来源的路线/ETA；换目的地不保留旧路线；公交是计划信息 |
| 草稿与周边 | 查看提醒草稿，复制/忽略，查周边和天气 | 复制不会自动发给联系人；POI 不能保证商家正在营业 |

## 常见情况

账号已存在时换一个账号名；忘记密码使用恢复码。登录失效可能因为会话到期、另一设备改密/找回、或超过五个会话被淘汰。退出不会删除服务器数据。

无声时先看文字是否已经生成，再检查手机媒体音量、耳机媒体音频开关及 App 显示的实际输出。不要把“已生成 TTS”当作实际听见。旧 Demo 的静态播放器初始化问题已经修改，新 APK 是否可听见仍需本轮真机反馈；工作模式本来就不主动播放。

“上一项操作仍在进行”表示当前账号正在处理录音或其他操作，稍等再试。网络超时后先看历史记录，避免盲目重新发送。每账号默认 24 小时窗口 300 次服务操作，聊天/识别与语音合成分别计数，地图、检索和纪要也计数；这不是 300 次完整语音对话。

“服务不可用”或证书问题请记录时间、App 版本和错误提示交给负责人，不在手机填其他 API Key，也不要关闭证书校验。登录与业务始终走 HTTPS IP。

## 反馈格式

发送：App 版本、手机型号/Android 版本、耳机型号、发生时间、操作步骤、期待结果、实际结果、脱敏截图。语音问题补充“是否识别出文字、是否有回复文字、是否实际听见、实际输入/输出设备提示”。不要发送密码、恢复码、Key 或他人私人录音。

公网服务器已通过合成音频的识别→文本回复→TTS、真实会议/记忆检索、地图及导出检查，临时测试账号已删除。这证明服务链路可用，**新 APK 的真实蓝牙听音仍需同事反馈**。Android 模拟器因宿主原生进程崩溃未完成运行，不能声称已有真机或模拟器截图验收。最新离线测试数量和云端记录统一见 [验收记录](acceptance.md)。部署操作由负责人按 [部署文档](android-deployment.md) 执行。

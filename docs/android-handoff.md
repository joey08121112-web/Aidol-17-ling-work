# Aidol Android 使用与交接

## 2026-10-17 语音记忆与显式锁屏会话

本节描述本次新源码/debug 构建；下文旧发布包、哈希和历史实机记录保持原版本含义。应同时更新本地后端和 Android，新增协议见 [API](api.md)。

1. 先登录并连接耳机；Rise 模式需实际连接/触控监听就绪。对话页展开“聆听方式”，选择“开启本次锁屏耳机会话”，授予录音与通知权限并保持通知可用。
2. 手动短语音说“记住，我答应客户周四交方案”，应明确返回已保存记忆、尚未建立提醒。工作模式手动提问现在可回应；连续/定时工作采集仍只记录。
3. 开启锁屏会话后锁屏，触控单击提问“我答应客户什么时候交方案”，再说“后来改成周五了”、再次问回、“忘记刚才那条”、最后问回应无依据。手机“查看最近回答依据”可核对原文和记录时间；更正/遗忘后旧证据立即撤回。
4. 通知中的“停止会话”结束本次授权。最长一小时；关闭任务、Activity 销毁、通话、Rise 断连后需重新开启。系统回收不自动恢复。服务不在后台接续连续或定时录音；系统蓝牙路径不新增未经验证的触控入口。
5. 双击切模式在当前轮次完成后生效，不丢弃正在录的片段；单击发送与长按取消保持原映射。失败时“查询上次请求结果”只读恢复状态，不会再次上传、执行工具或自动朗读。

语音更正/遗忘仅处理十分钟内唯一记忆；有多个候选、混合会议任务或只有转写时，需要先明确对象。任务完成仍在工作页操作，记忆保存不等于闹钟或位置提醒。遗忘范围含该记忆及明确关联原文/派生记录，独立记录和运维备份另行处理；不是全账号清空。

本次已通过离线单测、lint 和构建，USB 无设备，以上操作顺序是**待执行验收脚本**，不是成功的实机观察。请分别验收锁屏短语音、通知停止、双击保片段、佩戴→未知→摘下、来电/断连与音频路由；不得由构建成功推断手机放口袋可稳定使用。

## 2026-10-17 界面升级

本轮原生界面采用暖白底色、深松绿主操作和浅苔绿辅助区域，覆盖登录/注册/恢复账号及五个主页面，应用图标同步调整。对话页以语音卡片为主，记忆数量与置顶数合并为一行，工作页直接呈现记录和生成纪要，通勤页突出目的地，“我的”收起低频表单。统计来自真实快照，空数据不填演示值。

- 对话页“聆听方式”展开后选择手动、连续或定时；耳机状态条仍可打开设备详情。开发诊断位于“聆听方式”内，点击展开查看实际输入、输出与请求状态。
- “我的”中“陪伴偏好”“账号与隐私”，以及通勤中的“到达提醒”，点击标题展开；原有保存、导出、删除确认及 API 行为保留。
- 对话草稿在页面重建和切页时保留，刷新时恢复输入焦点/光标；退出账号和切换后端时清除。草稿仅在当前进程内，不承诺进程被系统回收后恢复。
- 主要交互目标至少 48dp，标签与输入框关联，选中项和折叠项提供读屏描述；导航、分段选项和主按钮按文字内容伸展。球体遵循系统关闭动画设置，离开窗口停止刷新，不读取音频设备；录音音量由已有会话回调提供。
- 新 APK 是本地 debug 构建 `app/build/outputs/apk/debug/app-debug.apk`；没有覆盖历史 release、上传官网或安装到用户手机。硬件协议、后端契约与 USB 开发流程未调整。

用户要求“展示精简，所有功能保留”。本轮删除装饰性中英文标语、重复标题和说明，保持业务入口与请求逻辑。空闲时不显示重复账号/模式状态行；同步、录音计时、处理、播放、错误和设备通知仍显示。隐私同意、恢复码、定位用途、录音结束规则、纪要草稿提示及危险操作确认继续保留。

| 功能 | 当前入口 |

### 离线界面检查入口

`src/androidTest/.../VisualReviewInstrumentation.java` 仅在测试 APK 中，用内存里的合成数据渲染登录、五个页签、空态与内容态，检查草稿保持和折叠交互，并输出截图。它不写账号数据、不发送文字或录音；若当前后端已有登录会话，会拒绝运行。使用专用测试设备上的未登录 debug 安装，勿为了测试清空开发者数据。

在 `android-app/` 构建 `./gradlew assembleDebug assembleDebugAndroidTest` 后，指定同一个 USB serial：

```sh
adb -s <serial> install -r app/build/outputs/apk/debug/app-debug.apk
adb -s <serial> install -r app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk
adb -s <serial> shell am instrument -w -e label phone com.aidol.app.debug.test/com.aidol.demo.VisualReviewInstrumentation
adb -s <serial> pull /sdcard/Android/data/com.aidol.app.debug/files/visual-review ../artifacts/android-visual-review
```

需人工查看截图，并在设备上检查小屏、大字体、横屏、键盘展开及 TalkBack；截图脚本不自动证明这些条件全部通过。测试完成后可卸载 `com.aidol.app.debug.test`，保留主 App。实际视觉验收状态见 [验收记录](acceptance.md)。

## 安装与第一次使用

1. Android 8.0 及以上手机安装服务器版 APK。系统提示时，仅对本次下载来源允许安装应用；后续更新使用负责人提供的同签名 APK。
2. 打开 Aidol，注册 3–24 位字母、数字或下划线账号，密码 8–128 位。账号全站唯一、忽略大小写，例如 `Alice` 和 `alice` 不能分别注册。
3. 保存注册成功显示的恢复码。忘记密码时用“账号 + 恢复码”重设；成功后会产生新恢复码，旧码失效。没有邮件或短信找回。
4. 先发一条文字消息，确认账号和服务连接正常。服务器地址已经内置，直接连接 `https://123.207.219.174:7776`，不需要域名或手动装证书。
5. 在手机系统配对蓝牙耳机，打开其“通话音频”和“媒体音频”。首次录音允许麦克风及系统要求的蓝牙权限；位置权限只在通勤定位时按需授权。
6. 切到生活模式，先试手动开始/结束录音。每次最多 60 秒，结束后才上传识别、显示文字并播放回复。也可主动选择连续轮次或生活定时录音：连续是在每轮处理/播放结束后接续，定时默认每 300 秒采集最多 30 秒，可在偏好调整。保持 App 当前页面在前台；停止、离开前台或错误后取消自动接续，本版没有后台常驻监听。

录音与文本会通过服务器调用 AI 服务。原始录音不写入账号数据库；对话、提取记忆和会议待办保存在自己的服务器账号。录制其他人讲话前先征得同意。AI 回答和会议纪要需要核对原话。

## 建议十分钟体验

| 步骤 | 操作 | 观察重点 |
| --- | --- | --- |
| 账号 | 注册、退出、重新登录 | 同一账号保留自己的记录；换账号不显示别人的记录 |
| 生活陪伴 | 文字或录音说“我喜欢清淡食物，请给我一个晚餐建议” | 转写与回复正常；生活模式能在耳机听到回复 |
| 连续/定时 | 主动开启一种前台录音方式，说完停顿；再按停止并切走 App | 自动接续按有界轮次处理；停止/离开前台后不得继续开麦；定时最长录音可设 5–60 秒 |
| 工作记录 | 切工作模式，分两段记录合成会议内容 | 显示转写和记忆，业务回答不自动朗读；新开发版仍播放操作提示 |
| 会议待办 | 生成选定时段纪要，查看来源，勾选任务完成 | 纪要是草稿；负责人/日期不能凭空生成，完成状态刷新后保留 |
| 问记忆 | 问“我喜欢什么口味”“有哪些未完成待办” | 有依据时显示引用；任务完成后不再作为未完成任务返回 |
| 记忆库 | 新增、编辑、收藏、搜索、删除；对话中“记住这句”后看原文 | 保存原句及来源；普通待办类型记忆与可完成的行动项有区别 |
| 通勤 | 搜索公共地标设目的地，选驾车/步行/公交，再更新位置 | 展示有来源的路线/ETA；换目的地不保留旧路线；公交是计划信息 |
| 草稿与周边 | 查看提醒草稿，复制/忽略，查周边和天气 | 复制不会自动发给联系人；POI 不能保证商家正在营业 |
| 隐私 | 导出数据；按需测试清空；单独测试账号可注销 | 清空保留账号和设置；注销需密码，删除在线身份与业务数据 |

不要用同事的真实会议、住址或敏感资料做第一轮测试，公共地标和合成内容足够验证功能。每人用自己的账号，恢复码和密码不要发到群里。

## 当前功能与边界

| 功能 | Android 服务器版 | 边界 |
| --- | --- | --- |
| 耳机录音与播放 | 真机系统蓝牙输入/媒体输出；debug可选Rise SDK麦克风；共用前台录音、服务器识别流程 | 最多60秒/次；真实输入来源、尾帧、目标路由和听音分别验收 |
| 文字聊天、语音回复 | 有；服务端统一密钥，带有限历史上下文，文字失败可规则降级 | 录音结束后处理，不是持续实时双工 |
| 工作/通勤/生活三模式 | 有；手动优先，可按时区/工作时段与场景自动判断 | 前台状态刷新/交互判断；不代表后台定时采集 |
| 工作静音、转写、多人会议内容 | 有；工作只记录，纪要保留原话依据 | 无声纹分离，不承诺远处/重叠发言识别，通用“用户”标签不是实名负责人 |
| 记忆提取与偏好设置 | 有；每账号独立偏好、事实、任务线索、行程 | 关闭转写保存不等于关闭记忆抽取，彻底删除用清空 |
| 记忆时间线/分类搜索/收藏/更正/删除 | 有 | 界面基于有界快照，不是无限全文数据库分页 |
| 手动记忆/记住这句/原文溯源 | 有；按原转写来源幂等 | 仅明确关联的原始转写可溯源 |
| 会议纪要与行动项 | 有；按所选时段工作记录生成、同快照复用、带引用 | 不自动识别单场会议；不同快照可能产生相似任务，需核对 |
| 待办完成状态 | 有；open/done 可切换并持久保存 | 普通 task 记忆只是线索，不自动等于行动项 |
| 问记忆与来源引用 | 有；结合自己的记忆、转写、行动项完成状态 | 资料不足明确提示，不替代开放式搜索或事实核查 |
| 地点搜索、定位与驾车/步行/公交路线 | 有；高德适配器复用，手动刷新定位 | 无后台位置跟踪，无实时公交车辆数据 |
| 到站/延误提醒与联系人草稿 | 有；ETA 或转写关键词触发，复制/忽略 | 没有短信、微信等发送接口，绝不自动发送 |
| 周边 POI 与天气 | 有 | 需要服务器地图权限和可用网络；天气按城市代码查询 |
| 数据导出/清空 | 有；导出 v3 JSON，清空需要密码 | 保留账号/设置；导出每集合最多 10000 条，备份由负责人管理 |
| 注册/登录/改密/找回/注销 | 新增；唯一账号，无邮箱短信，恢复码找回 | 30 天会话、最多五个登录会话；改密/找回会撤销旧会话 |
| 页面每五分钟录 30 秒 | 有；生活模式前台定时，本次手动开启，默认 300 秒/30 秒，可调整 | 停止或离开前台取消，不在后台常驻；每轮分别上传处理 |
| VAD 与连续交互 | 连续/定时的非工作模式可在说完静音约 1.2 秒后收尾，连续模式再接下一轮 | 不是实时双工，也不是播放中 VAD 打断 |
| 语音服务 | 固定 ASR→文本→TTS 托管路径 | 供应商凭证和识别方式由后端管理，App 不提供直连 Key 或原生实时通道切换 |
| 厂商状态与控制 | debug Rise SDK显示实际电量/佩戴；本轮VI-A10握手与属性上报已观察 | 未上报保持未知；短语音与听音待验，ANC、按键、闪录、盒子、唤醒未接 |

## 常见情况

账号已存在时换一个账号名；忘记密码使用恢复码。登录失效可能因为会话到期、另一设备改密/找回、或超过五个会话被淘汰。退出不会删除服务器数据。

无声时先看文字是否已经生成，再检查手机媒体音量、耳机媒体音频开关及 App 显示的实际输出。不要把“已生成 TTS”当作实际听见。当前构建是否可听见仍需本轮真机反馈；工作模式本来就不主动播放。

“上一项操作仍在进行”表示当前账号正在处理录音或其他操作，稍等再试。网络超时后先看历史记录，避免盲目重新发送。每账号默认 24 小时窗口 300 次服务操作，聊天/识别与语音合成分别计数，地图、检索和纪要也计数；这不是 300 次完整语音对话。

“服务不可用”或证书问题请记录时间、App 版本和错误提示交给负责人，不在手机填其他 API Key，也不要关闭证书校验。登录与业务始终走 HTTPS IP。

## 反馈格式

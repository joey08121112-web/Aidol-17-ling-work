## 本轮 M0/M1 开发交接

当前源码已增量接入 USB 真机本地后端与 Rise SDK 6.7 短录音。debug 后端只有“本地电脑服务”和“远端服务器”，音频只有“系统蓝牙兼容”和“Rise SDK 麦克风”；本地固定 USB `127.0.0.1:8108`，远端使用 HTTPS，模拟器已退出当前产品入口。“我的”有设备详情，对话页有状态入口；连接就绪后仍需用户主动开始录音，结束等待停止确认和尾帧排空，取消丢弃未提交音频。工作静音、锁屏/切页结束本轮，未实现实时双工或后台录音。Windows/macOS 具体步骤见 [本地测试](android-local-testing.md)。

换电脑或交给下一位AI必须同时提供 **官方 Word、demo_6_7.zip 和包含当前未提交改动的源码快照**，详见 [分工与交接清单](android-m0-m1-handoff.md)。原有网站等未提交工作也保留在快照；不能只发main的HEAD提交。新开发APK不代表公网旧release已更新，发布策略仍系统蓝牙+HTTPS。

下文公网安装与哈希是既有发布版记录，本轮SDK功能请使用新debug构建。SDK电量/佩戴只显示真实收到的属性，未知仍为未知；ANC、按键、闪录、盒子和后台唤醒不在本轮。

这是给同事体验的同一个原生 Android 项目。开发者在 Windows/macOS 启动本地后端，通过 USB 安卓真机 Run；普通测试者在手机安装负责人发送的 **aidol-android.apk**，注册账号连接远端服务器。无需网页版，也不重做跨平台客户端。

手机发布版无需电脑、`.env`、Viaim Key、语音 Key、邮箱或短信验证码。交付源文件 `android-app/aidol-android.apk`，包名 `com.aidol.app`，版本 0.2.0，release 签名。旧直连供应商 Demo 已从项目移除，用户只使用此账号客户端。

## 安装与第一次使用

1. Android 8.0 及以上手机安装服务器版 APK。系统提示时，仅对本次下载来源允许安装应用；后续更新使用负责人提供的同签名 APK。
2. 打开 Aidol，注册 3–24 位字母、数字或下划线账号，密码 8–128 位。账号全站唯一、忽略大小写，例如 `Alice` 和 `alice` 不能分别注册。
3. 保存注册成功显示的恢复码。忘记密码时用“账号 + 恢复码”重设；成功后会产生新恢复码，旧码失效。没有邮件或短信找回。
4. 先发一条文字消息，确认账号和服务连接正常。服务器地址已经内置，直接连接 `https://123.207.219.174:7776`，不需要域名或手动装证书。
5. 在手机系统配对蓝牙耳机，打开其“通话音频”和“媒体音频”。首次录音允许麦克风及系统要求的蓝牙权限；位置权限只在通勤定位时按需授权。
6. 切到生活模式，先试手动开始/结束录音。每次最多 60 秒，结束后才上传识别、显示文字并播放回复。也可主动选择连续轮次或生活定时录音：连续是在每轮处理/播放结束后接续，定时默认每 300 秒采集最多 30 秒，可在偏好调整。保持 App 当前页面在前台；停止、离开前台或错误后取消自动接续，本版没有后台常驻监听。

录音与文本会通过服务器调用 AI 服务。原始录音不写入账号数据库；对话、提取记忆和会议待办保存在自己的服务器账号。录制其他人讲话前先征得同意。AI 回答和会议纪要需要核对原话。

| 步骤 | 操作 | 观察重点 |
| --- | --- | --- |
| 账号 | 注册、退出、重新登录 | 同一账号保留自己的记录；换账号不显示别人的记录 |

| 连续/定时 | 主动开启一种前台录音方式，说完停顿；再按停止并切走 App | 自动接续按有界轮次处理；停止/离开前台后不得继续开麦；定时最长录音可设 5–60 秒 |
| 工作记录 | 切工作模式，分两段记录合成会议内容 | 显示转写和记忆，保持安静，不主动播放 |
| 会议待办 | 生成选定时段纪要，查看来源，勾选任务完成 | 纪要是草稿；负责人/日期不能凭空生成，完成状态刷新后保留 |
| 问记忆 | 问“我喜欢什么口味”“有哪些未完成待办” | 有依据时显示引用；任务完成后不再作为未完成任务返回 |

## 常见情况

账号已存在时换一个账号名；忘记密码使用恢复码。登录失效可能因为会话到期、另一设备改密/找回、或超过五个会话被淘汰。退出不会删除服务器数据。

无声时先看文字是否已经生成，再检查手机媒体音量、耳机媒体音频开关及 App 显示的实际输出。不要把“已生成 TTS”当作实际听见。当前构建是否可听见仍需本轮真机反馈；工作模式本来就不主动播放。

“上一项操作仍在进行”表示当前账号正在处理录音或其他操作，稍等再试。网络超时后先看历史记录，避免盲目重新发送。每账号默认 24 小时窗口 300 次服务操作，聊天/识别与语音合成分别计数，地图、检索和纪要也计数；这不是 300 次完整语音对话。

“服务不可用”或证书问题请记录时间、App 版本和错误提示交给负责人，不在手机填其他 API Key，也不要关闭证书校验。登录与业务始终走 HTTPS IP。

## 反馈格式

发送：App 版本/代码提交、Windows/macOS 系统、手机型号/Android 版本、耳机型号、后端目标、音频来源、发生时间、步骤、预期与实际结果、脱敏截图。语音问题补充有无转写/回复、是否实际听见、输入/输出设备提示、电平、session/request ID 和阶段错误；USB 问题补充授权和 reverse 状态。不要发送密码、Token、恢复码、Key、完整设备身份或私人录音。

公网服务器既有合成音频 ASR→文本→TTS、会议/记忆检索、地图及导出记录只证明当时服务链路可用。当前 Windows 真机已观察 Rise 就绪与属性上报，仍需完成手机 USB 请求、短语音、人耳听音以及断连、来电、锁屏等验收；macOS 未实测。最新构建、测试和分层结果统一见 [验收记录](acceptance.md)。部署由负责人按 [部署文档](android-deployment.md) 执行。

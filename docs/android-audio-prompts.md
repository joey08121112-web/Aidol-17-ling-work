# 安卓操作语音提示

用户要求切模式、开始和结束时简短播报。App 内置五段固定中文提示：生活模式、工作模式、通勤模式、开始录音、录音结束。单击开始/结束，双击切模式，长按取消的映射不变。

这些是固定产品音频源资产，不含用户录音或供应商凭证。运行时无需手机中文语音包或额外网络合成请求；Windows 与 macOS 构建均直接使用 `android-app/app/src/main/res/raw/cue_*.wav`。

## 播放顺序

- 开始：先核验所选耳机的实际输出并播“开始录音”，提示结束后才启动麦克风。提示失败不自动开麦。
- 结束：SDK 确认停止、尾帧排空并释放录音焦点后播“录音结束”，再上传本轮。普通提示播放失败不丢弃已经完成的录音；明确取消、后台或设备断连仍按会话规则停止。
- 模式：后端确认设置成功后才播对应模式；提示播放失败不撤销已生效的模式。处理中的语音仍不能因切模式被误取消。
- 工作模式播放这些操作提示，业务回答继续遵守 `speak=false`，不自动朗读工作记录。

所有提示共用 `ReplyPlayer` 的蓝牙输出核验。Rise 输入必须匹配当前连接 Rise 的实际输出地址，不能回落到手机扬声器。提示不与录音同时播放；离开前台、取消或断连可中断提示，结束后不自动续录。

## 音频来源与维护

2026-10-17 使用本机 Microsoft Huihui Desktop 中文语音、语速1，合成 `scripts/android_cues.json` 中的五句固定文案。格式均为 24 kHz、PCM16、小端、单声道 WAV，约1.5–1.7秒；没有调用供应商或录制真人声音。

如需更新文案，在装有该语音的 Windows PowerShell 5.1 中执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/generate_android_cues.ps1
```

普通开发者无需运行生成脚本。修改后须验证格式、实际耳机听音和开始/结束顺序。源码交接包仅对这五个固定路径放行 WAV，仍排除用户录音、数据库、密钥和构建产物。真机实测结果见 [验收记录](acceptance.md)，生成文件或构建通过不等于人耳已听到提示。

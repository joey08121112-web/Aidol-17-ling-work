# 安卓操作语音提示

当前三模式命名、提问/记录区别及文字与语音一致性，统一见[三种模式的文案与播报约定](mode-experience.md)。历史版本说明不覆盖当前约定。

模式提示统一为“生活模式 / 工作模式 / 通勤模式”。定时聆听和安静记录另有“开始录音 / 录音结束”提示；单句提问和 AI 通话使用简短开始耳标。单击空闲时接通 AI、聆听时发送、回复时打断；双击切模式，长按停止。其他操作短提示以 `scripts/android_cues.json` 为准。

这些是固定产品音频源资产，不含用户录音或供应商凭证。运行时无需手机中文语音包或额外网络合成请求；Windows 与 macOS 构建均直接使用 `android-app/app/src/main/res/raw/cue_*.wav`。

## 播放顺序

- 环境采集开始：先核验所选耳机的实际输出并播“开始录音”，提示结束后才启动麦克风。提示失败不自动开麦。主动提问/通话使用开始耳标，连续通话后续轮次不重复播放开始提示。
- 环境采集结束：SDK 确认停止、尾帧排空并释放录音焦点后播“录音结束”；流式上传可先提交结束帧，与提示并行收尾，普通上传在提示后提交。主动提问/通话不播放结束语音。普通提示播放失败不丢弃已经完成的录音；明确取消、无锁屏授权时离开前台或设备断连仍按会话规则停止。
- 模式：后端确认设置成功后才播对应模式；提示播放失败不撤销已生效的模式。提示播放期间可再次点击模式或双击耳机切换：立即停止旧提示，提交新模式，确认成功后只播新模式。耳机手势仍保留组合判定和防抖；提示自然结束不会丢失正在判定的双击。处理中的语音仍不能因切模式被误取消。
- 工作模式允许操作提示；安静记录的业务回复 `speak=false`，主动语音提问与文字对话可 `speak=true`。

所有提示共用 `ReplyPlayer` 的蓝牙输出核验。Rise 输入必须匹配当前连接 Rise 的实际输出地址，不能回落到手机扬声器。提示不与录音同时播放；无锁屏授权时离开前台、取消或断连可中断提示，是否接续由单句/通话/定时/记录方式决定，提示本身不授权下一轮录音。显式锁屏会话有效时，模式切换确认也可向已核验的耳机播放。

## 音频来源与维护

2026-10-17 使用本机 Microsoft Huihui Desktop 中文语音、语速1，合成 `scripts/android_cues.json` 中的固定文案。格式均为 24 kHz、PCM16、小端、单声道 WAV，时长随文案变化；没有调用供应商或录制真人声音。

如需更新文案，在装有该语音的 Windows PowerShell 5.1 中执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/generate_android_cues.ps1
```

普通开发者无需运行生成脚本。修改后须验证格式、实际耳机听音和开始/结束顺序。源码交接只允许固定产品提示音，仍排除用户录音、数据库、密钥和构建产物。真机实测结果见 [验收记录](acceptance.md)，生成文件或构建通过不等于人耳已听到提示。

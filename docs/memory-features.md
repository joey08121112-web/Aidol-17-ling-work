# 会议纪要、问记忆与记忆时间线

这些功能位于「全局记忆」，使用当前电脑的 SQLite。文本 AI 复用现有 `TEXT_API_KEY/TEXT_BASE_URL/TEXT_MODEL`；无需注册新的记忆服务。没有文本模型或调用失败时，纪要和问记忆使用本地规则/摘录，界面会区分来源。模型与耳机能力的真实验收见 [acceptance.md](acceptance.md)，本说明不宣称额外的测试已经通过。

## 把工作记录整理成纪要

1. 进入工作模式，开启耳机录音并产生转写；也可以输入文字并填写发言人。设置中需要允许保存原始文字转写。
2. 在「全局记忆」选择最近 1 小时、24 小时或 7 天，点击「生成纪要与待办」。
3. 查看纪要、结论与原话依据，核对模型是否正确理解。负责人和截止时间不明确时保持空白/未明确，不能据此自行补成某个人或日期。
4. 在行动项列表勾选完成，或取消勾选恢复待完成；可按状态筛选。状态保存在本机，刷新后保留。
5. 需要分享时点击「复制纪要」。系统只复制文本，不发送给联系人，也不创建外部日历事项。

该功能整理的是一个时段内的工作记录，**尚未识别独立会议边界**。接口从最近最多 1000 条转写中选最近最多 80 条工作记录；模型输入另限单条 2000 字、总量 18000 字，不能保证覆盖该时段全部对话。想集中整理刚结束的会，可先选择最近 1 小时，再检查来源列表。

默认不使用模拟演示数据。需要演示时勾选「包含模拟演示记录」，生成报告会保留模拟标记。同一批输入命中缓存，不重复生成行动项；输入快照改变后可能创建新报告和相似任务，当前没有跨报告语义合并。界面展示最新一份纪要，导出可包含历史报告。

普通记忆里的「待办线索」没有完成状态；只有行动项表中的勾选结果能回答是否已完成。生成的纪要是待核对草稿，不等于已经执行任务、核实所有结论或完成会议签字确认。

## 向记忆提问

在「找回线索」输入问题，例如「我有什么饮食偏好？」「我答应了什么？」「还有哪些未完成的待办？」。

- 系统先检索本地记忆、转写和行动项，再选择相关记录的原文摘录，展示引用供核对。
- 当前不是自由生成的聊天问答，也不会联网补全不存在的事实；没有足够证据会直接说明。
- 模型输出的引用 ID 与原文子串会被校验。此校验防止编造引用，不保证每条命中都最相关，仍应查看来源。
- 「未完成的待办」只使用明确带完成状态的行动项；不能根据一段旧承诺推断今天仍未完成。
- 行动项证据包含结构化的负责人、截止与用户更新的状态，属于待办表记录，不是录音逐字原话。
- 检索范围有数量上限，不能当作全历史、向量语义检索或完美的人物关系记忆。资料更新后应重新提问。
- 「听听回答」使用现有 TTS 和音频输出；工作模式仍保持安静，需切换允许播放的模式后使用。

## 管理记忆时间线

**立即记住：** 在记忆页选择类型并输入内容，点击「立即记住」，保存用户主动输入的笔记。它不依赖新模型，也不会把笔记自动变成可执行指令。

**记住这句：** 在实时对话的某条转写上点击「记住这句」，保存完整原句为事实笔记，并明确关联那条转写。新笔记默认不收藏。重复点击复用已有来源笔记，保留用户之后的更正和收藏；不会不断生成副本。

**重要收藏：** 点击「重要收藏」或取消收藏。收藏集中显示在时间线顶部，普通记录按设置时区分日期；可用「只看重要收藏」叠加关键词和类型筛选。收藏表示用户重视，不代表内容经过核实。

**更正内容：** 点击卡片的「更正内容」，在上方表单修改内容或类型后保存。原始创建时间与来源保留，界面标记已修改；原始转写不会被一起改写。这里没有承诺自动重算之前生成的所有纪要和任务，旧报告仍是当时的快照。

**查看原话：** 从转写保存的笔记可展开准确来源；普通自动提取记录只有提取方式，不能保证对应某条精确原话。找不到来源时应显示错误，而不是猜一段相似文本替代。

**删除、导出、清空：** 单条删除只删该笔记；「导出数据」返回 v2 JSON，包括记忆、转写、草稿、设置、纪要和行动项。全量清空同时删除纪要、行动项等本地记录，但保留设置；应先停止录音。没有一键导入或云端回收站，按需先导出。

页面使用有限状态快照，通常最多显示 100 条记忆和 100 条转写，不是数据库总量。重要收藏优先返回；大量数据时应检查导出，不能把搜索无结果直接理解为从未记录。

## 本地协作与接口边界

- 每人使用自己电脑上的数据与音频设备；拉代码不会同步别人的会议、收藏或待办。
- 旧版 SQLite 会迁移收藏和修改时间字段；无需删库重建。
- 三种功能均不要求 Viaim 私有按键 API；当前入口是 Web。未接 SDK 时不宣称耳机按键收藏、离线采集或全天后台录音。
- 本功能借鉴记忆产品的闭环思路，但没有接入硅基记忆、Remmy 或其他第三方记忆平台。
- 完整请求、字段、上限、错误与导出契约见 [api.md](api.md)。内容修改不等于历史推理链自动修正，关键结论仍需人工核对。

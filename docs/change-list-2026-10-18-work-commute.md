# 工作页与通勤地图更新清单（2026-10-18）

本批整理本地工作页、通勤地图、高德导航和字标更新，并与仓库最新主线的性能优化、生活语音界面更新一起验证。前一批已提交功能见 [此前清单](change-list-2026-10-18.md)。

## 本地功能更新

- 工作页用“会议纪要 / 历史整理 / 行动清单”三个选项卡展示对应模块；保留各模块浏览位置，迟到的行动项勾选回执不会移动当前模块。
- 通勤起点、目的地与方式控件缩为紧凑圆角选择区；上方显示高德底图、端点与完整路线，可点击放大。
- 目的地天气自动展示和定时更新，取消原附近及手动天气按钮组。路线预览独立于正在进行的通勤，旧请求不能覆盖新选择。
- 新增“高德导航”按钮，仅在通勤服务就绪后启用，使用已确认的活动行程参数。当前位置驾车及受支持版本的步行、骑行直接唤起导航；固定起点、公交与兼容入口打开高德路线页。其余偏好沿用高德设置。
- 未安装或无法打开高德时可改用网页版路线；窗口支持取消和失败恢复。导航不结束后台通勤，也不切换模式。
- 更新 Aidol 字标资源，保持已确认的黑蓝配色。

## 后端与兼容

- 新增鉴权的 `POST /v1/commute/preview`、`POST /v1/maps/snapshot`，保存服务端高德密钥边界及坐标、路径、图片体积限制。
- 路线携带 GCJ-02 线形，优先选择较短候选。天气与地图预览不占用语音业务锁；三个只读入口仍按账号查询额度限制，不适用普通业务的单账号锁与全局活动数上限。
- 原来的会议、行动项提醒、蓝牙维护、前台每3分钟定位及主动通勤后的锁屏更新保留。最新主线的网络池、内存/界面缓存和生活模式界面也须保留。

## 已有验证与交付范围

合并前已有612项后端测试、252项Android单测、编译和Lint通过。荣耀ANN-AN00 / Android15完成8种导航参数组合及失败回退的隔离真机检查，高德17.01实际显示公开地标的正确驾车路线；真实道路语音导航未实测。详细证据与限制见 [验收记录](acceptance.md)。

本次提交仅包含源码、产品资源、测试和文档；数据库、录音、密钥、签名和生成的APK不入库。合并后从远端主线重新拉取、构建并更新手机，服务端按同一版代码更新本地实例，不等同于发布公网服务器或官网安装包。
